DBA

Prior work

Dynamic block activation (DBA), developed by Ruoyao Zhang and Yang Xia, is an adaptive acceleration framework for continuum simulations. It partitions fixed-grid data into blocks aligned with GPU thread blocks, using shared-memory states and block synchronization to coordinate full, reduced, or idle computation. Keeping field data and activation decisions on GPUs reduces CPU–GPU transfers, with only minor changes to existing solvers. Applications span materials science, biophysics, and fluid dynamics, and the framework demonstrated near-ideal strong and weak scaling in the reported multi-GPU tests.

Ruoyao Zhang and Yang Xia. A dynamic block activation framework for continuum models. Nature Computational Science 5, 345–354 (2025).

sp-DBA

To address the difficulty of introducing block adaptivity into transform-domain workflows, we developed sp-DBA, a GPU-friendly adaptive acceleration framework for scientific and engineering solvers. I led its design and implementation under Prof. Yang Xia’s supervision. The framework redesigns computational blocks for transformed data and coordinates adaptive decisions with both solver operations and GPU execution. Lightweight interfaces let existing solvers retain their equations, numerical methods, and highly optimized transform libraries. Framework and model equations →

We tested the framework in polycrystalline coarsening, pattern formation, and optical signal processing. I am also exploring how these ideas might extend to other transforms, multiresolution methods, and unstructured meshes.

Jingkun Jiang, Pingchuan Deng, and Yang Xia. sp-DBA: a general framework for adaptive transform-domain computation. arXiv (2026).

Key advantages

  1. Efficient GPU execution. Hardware-aligned block adaptivity reduces unnecessary updates and thread divergence.

  2. Complementary acceleration. Works alongside optimized transforms and model-specific acceleration.

  3. Solver compatibility. Preserves equations, discretization, and transformed representations.

  4. Lightweight integration. Reuses existing update routines with minimal solver-specific code changes.

Polycrystalline coarsening

Phase-field crystal (PFC) models describe crystal microstructure through a spatially periodic density field. In our coarsening tests, the dominant Fourier amplitudes concentrate near Bragg rings (ring-shaped features associated with the crystal lattice), providing localized spectral blocks for sp-DBA to update selectively. Pattern formation

Reaction–cross-diffusion (RCD) models describe interacting species and coupled transport. More components make Fourier-space updates increasingly costly, giving selective execution greater value for complex pattern-forming systems. I combined sp-DBA with eigendecomposition, retaining close agreement with full-update morphologies and structure factors in the tested cases. More details →

Optical signal processing

Digital backpropagation (DBP) is an engineering transform-domain workflow for recovering signals propagated through multimode optical fibers. I integrated sp-DBA into the repeated frequency-domain linear updates of a split-step solver. Controlled Gaussian wave-packet tests retained close agreement with the transmitted reference; in the reported benchmark, the frequency-domain linear updates were 21.3× faster than full-update Regular. FFT & distributed FFTs

I developed a multi-GPU PFC workflow combining distributed Fourier transforms with sp-DBA. End-to-end profiling showed how local update savings interact with global transform and communication costs.

I also wrote a small FFT library and compared it with FFTW, exploring how decomposition and memory access affect runtime.

Materials modeling

Grain boundaries & defects

I built a pipeline that converts single-layer phase-field crystal (PFC) density fields into grain orientations and size statistics, using C++/CUDA for peak extraction and Python for grain reconstruction and statistics. OVITO supports inspection and visualization. More details →

Structural phase-field crystal (XPFC)

XPFC uses correlation kernels C2 to select lattice spacings and symmetries. I implemented Fourier-space solvers to compare how different kernels shape two-dimensional density patterns and spectra. More details →

Amplitude phase-field crystal (APFC)

APFC describes crystal order through slowly varying complex amplitudes Aj and reconstructs the density ψ. I implemented CPU and GPU Fourier-space solvers and inspected grain contact through reconstructed density, amplitude, and phase fields. More details →

Dendritic growth

I implemented a three-dimensional phase-field solver coupling crystal growth with heat diffusion, using finite differences and CPU/GPU parallel versions. By varying anisotropy, undercooling, temperature sensitivity, and seed size, I examined how these choices affect branching and tip shape. More details →
