PF · Dendrites and phase separation

p runs from liquid at 0 to solid at 1, while T is dimensionless temperature. Interface width ε, relaxation time τ, and directional driving m govern growth. The temperature equation includes released latent heat.

δ controls cubic anisotropy and γ controls temperature sensitivity. My code uses σ = 1 when the phase gradient vanishes.

A plausible dendrite shape was only a starting point. I varied anisotropy, undercooling, temperature-related parameters, and seed size while inspecting the coupled phase and temperature fields. I also reorganized the finite-difference loops and memory layout before building parallel versions. These snapshots record how the developing morphology responded to those choices.

Reactive Model B · A spectral implementation

I started from the reactive Model B example used in DBA and rewrote its three-dimensional solver with Fourier pseudo-spectral differentiation and semi-implicit time stepping. The CPU version uses FFTW; the GPU versions use cuFFT. For the adaptive prototype, I grouped Fourier coefficients into CUDA blocks and based activation on changes in the three concentration fields, with neighboring blocks also reactivated. Nonlinear chemical potentials and reactions are evaluated in real space, while transforms cover the full domain. I inspected concentration fields, Fourier amplitudes, and activation maps as phase separation developed.
